# AI Engineering

A production-focused AI engineering portfolio built around six integrated systems.

## Projects

1. Production RAG
2. Model Router
3. Security Middleware
4. Evaluation + Observability
5. Multi-Agent Research
6. AI Platform

## Architecture

The projects are developed as independent production-oriented services and integrated through the AI Platform.

The AI Platform provides the application-level gateway that connects the RAG, routing, security, evaluation, model, and multi-agent research capabilities into a unified system.

## Development Principles

- Local-first where practical
- Dockerized services
- Test-driven development
- Observable systems
- Security by design
- Reproducible deployments
- Explicit service boundaries
