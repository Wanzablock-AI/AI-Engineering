A production-oriented Retrieval-Augmented Generation system with:

- PDF ingestion
- Document chunking
- Embeddings
- Hybrid retrieval
- SQLite-vec
- Cross-encoder reranking
- LangGraph orchestration
- Grounded answers
- Page-level citations
- Local Ollama inference
- FastAPI API
- Docker deployment
- Automated tests
